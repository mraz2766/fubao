# Animata adaptations

Source: https://github.com/codse/animata/tree/de9aabb0eed14e0db944bb07720961ddc450c672
License: MIT, Copyright (c) Animata. Full license: /licenses/animata.txt.

SlideArrow ports the expanding accent and label movement to a server-rendered link.
TiltedCover ports layered perspective covers; photos stay visible and one tap opens the destination.
RingChart visual treatment and Fluid Tabs inform the shared CSS. These are CSS adaptations, not a Motion runtime installation.

Transitions are 180–250 ms. Focus and touch are supported; reduced motion disables movement.
