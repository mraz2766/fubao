# Animata interaction reference

Fubao retains compact tabs and short press/selection transitions adapted from Animata.
These styles live in the shared CSS and use server-rendered markup; no Motion runtime is shipped.
The former Slide Arrow and Tilted Cover components were retired in the neutral interface redesign.
