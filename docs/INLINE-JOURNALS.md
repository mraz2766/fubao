# 首页与同页记录（2026-09-14）

首页收敛为健身、旅行两个模块。原周活动、最近动态不再独立展示；旧 Widget 数据与备份格式保持兼容，设置只管理两个可见模块。

健身主页面使用 FitnessJournal 组织表单和本周、最近记录。新表单仅在用户点击保存时写入；训练项或动作至少选一个，其他字段选填。复用 WorkoutEditor 与版本控制；已有记录按需读取完整动作和组，自动保存、完成操作均原地更新列表。动作选择内嵌并按训练项展示相关结果。历史、统计、模板、完整动作库保留辅助链接。

旅行主页面使用 TravelJournal，复用 TravelEditor 的压缩、上传、EXIF 建议和校验。新增及编辑均在主页面完成，保存后更新照片记录列表。地图、想去清单按需展开和下载；旧页面链接继续有效。

不修改 D1 Schema、登录权限、R2 存储约定、API 和备份格式，不增加依赖。公开访问仍仅返回公开记录；本人表单只在登录后显示。

验证入口：`pnpm check`、`pnpm test`、`pnpm build`、`pnpm exec playwright test tests/e2e/inline-journal.spec.ts`。原先依赖即时打卡、顶部 Tab 和旅行创建弹窗的 UI 测试属于旧流程；新交互由 inline-journal 覆盖，数据、权限和版本控制测试继续沿用。

本轮验证：63 项领域测试；10 项相关端到端与 D1 回归（含 320/390/768/1440px、axe、英文深色 Reduced Motion、丢失回执重试、动作空字段组、旅行原地编辑、照片权限）；类型检查与构建通过。
