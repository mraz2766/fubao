# Fubao 移动端重构

## 范围

保留 Astro、Cloudflare Workers、D1、R2、现有登录与 API。未改数据库结构，未迁移现有数据，未部署到线上。

实施前使用测试账号体验了线上首页、健身、训练录入与动作选择、训练历史与详情、旅行、新增旅行、旅行详情、旅行编辑和设置。线上未新增或删除记录。浏览器回归使用本地数据库与项目测试图片。

## 页面和交互

- 全局：`Base.astro` 作为 App 外壳，统一底部「首页 / 健身 / ＋ / 旅行 / 设置」。PC 沿用紧凑居中布局。
- 首页：仅今日训练和最近旅行，继续尊重首页模块的显示和排序设置。
- 健身：今日训练直接记录，下方是最近训练。统计、模板、动作库、日期筛选收纳至更多训练工具。
- 训练表单：在当前页面打开 Bottom Sheet；日期、训练部位、动作、组数值同一界面完成。下一组复用前一组数值；保存时把已填写的有效组记为完成，空白占位组不计入。
- 训练详情：标题、日期和动作记录为主，相邻且内容相同的组合并显示，RPE、备注与完成状态仍保留。统计数据可展开。
- 旅行：单列照片 Feed；新增与编辑使用 Bottom Sheet，照片在前，地点、日期、描述在后。保留压缩、HEIC、上传重试、最多六张、删除与顺序调整；增加拍照入口。
- 旅行详情：照片在前，地点、日期与描述在后；编辑和删除收纳进右上角「•••」。
- 设置：简单分组列表，保留外观、语言、单位、时区、首页模块、数据备份、账号和关于；增加 iPhone 安装说明。
- 四个旧新增/编辑路由保留为兼容入口，转入同一套弹层，不再维护单独编辑页面。模板和地点链接继续可用。
- 保存留在来源页面并显示反馈；关闭弹层保留未保存提醒，保存期间阻止误关闭。沿用 Radix 的焦点约束、Esc 和背景滚动锁定。

## PWA 与 iPhone

- 保留并更新 manifest 的 standalone、start_url、scope 和主题色。
- 增加 Apple Web App meta、180px Apple Touch Icon，复用现有手绘植物 App 图标。
- 保留 `viewport-fit=cover`，顶部、底栏、弹层适配 safe-area；使用 `100dvh` 和 VisualViewport 应对动态高度与软键盘。
- 主要按钮与操作目标至少 44px；克制的 160–220ms 反馈和弹层动效，支持减少动态效果。
- Service Worker v7 缓存基础静态资源并提供离线页；修复 Cloudflare `.html` 重定向导致离线响应不可用的问题。
- 不缓存私人 HTML、API 或照片。离线时无法读取和新增私人记录，联网后再使用；没有后台自动提交队列。
- Service Worker 和 manifest 使用 `Cache-Control: no-cache`，更新按浏览器的正常 Service Worker 生命周期生效。

## 紧凑版调整（2026-09-16）

- 默认训练记录为日期、可选时长、两排等宽居中的训练部位；选部位即可保存，不要求添加动作。
- 动作明细借鉴 [Strong 官方记录流程](https://help.strongapp.io/article/229-my-first-workout) 和 [Hevy 记录界面](https://www.hevyapp.com/features/track-workouts/)：同屏填写每组重量/次数，在动作下添加组。Fubao 的补录表单统一保存，无需逐组确认；部位简记是针对本项目需求的适配。
- 每组的 RPE、备注、复制、删除收进更多菜单；训练备注和时间设置按需展开。已有明细可直接修改。
- 减少页面顶部、分区与字段间距、照片选择区域高度；保留 44px 触控目标与 16px 输入字号。

### 安装到手机

部署此版本到生产后，用 iPhone 的 Safari 打开 https://fubao.mraz2766.workers.dev/ ，点击分享 → 添加到主屏幕 → 添加。若系统显示“作为网页 App 打开”，保持开启。打开桌面 Fubao 并登录。Android Chrome 使用菜单 → 添加到主屏幕 / 安装应用。

`localhost:8787` 是电脑本地预览地址，不是手机可安装的线上地址。本次代码提交不等于生产部署。
