# 分类浏览与交互减负

## 动作选择

- 默认按胸、背、腿、肩、手臂、核心、有氧、其他八类浏览；已选一个训练部位时直接进入对应分类。
- 只按主要目标肌群归类，不再因辅助肌群把动作混入其他部位。已有相关动作 API 参数继续兼容。
- 合并最近使用、常用、收藏入口为“常用”，集合为用过或收藏过的动作。分类内按收藏、使用次数及最近使用排序；未使用的动作仍可浏览。
- 搜索保留；器械和只看收藏收进一个折叠区，器械归并为徒手、哑铃、杠铃、绳索、固定器械、其他器械六类。
- 跨分类多选保留已选项，一次添加。列表用“加载更多”追加结果，避免往返翻页。空筛选可清除，网络失败可重试。
- 独立动作库列表仅保留查看入口，收藏和加入训练留在详情，减少每行竞争按钮。

## 共用交互

- 健身一级选择只保留记录、动作；按日期、模板、分析收进更多工具，删除重复入口。
- 语言、重量单位、周起始日改成直接点选；周目标改为加减步进，保留 1–21 次范围。
- 地点默认仅展示 3 个最近地点、5 个搜索结果，可展开更多。切换地点不主动聚焦输入框，过期请求不能覆盖当前选择。
- 旅行日期与备注在新建时按需展开；已有数据保留。设置切换主题时同步使用新的冷灰主题色。
- 在 AGENTS.md 中记录“一次一个主要决定、复用已有选择、低频按需展开、不主动弹键盘”的项目设计约定。

## 接口

`GET /api/fitness/exercises` 增加可选 `category`、`equipmentGroup`、`favorites=1`，以及 `mode=recommended|usual`。基于现有数据动态归并，不改数据库结构；原有搜索参数继续保留。非法分类返回 400。

## 验证

- 本地完整遍历 1,324 个动作：胸 163、背 203、腿 286、肩 143、手臂 329、核心 169、有氧 29、其他 2；分类总数与动作库总数相同，无重复归类。
- 新增分类和器械归并测试；87 项测试通过，Astro 检查与生产构建通过。
- 浏览器验证跨部位选择两个动作后批量添加；“加载更多”从 20 项追加至 40 项；器械筛选只有六类加不限。
- 周目标加一后减一，保存成功并恢复原值；旅行备注默认折叠，切换地点不聚焦输入框。
